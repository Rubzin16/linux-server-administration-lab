# Linux File and Directory Permissions

## Objective
Understand Linux file permissions, ownership and access control.

## Tasks Completed 
1. Created confidential.txt and team-notes.txt.
2. Used chmod 600 to restrict confidential.txt.
3. Used chmod 644 to configure team-notes.txt.
4. Used chown to assign ownership to labuser1.
5. Used chgrp to assign the cloudadmins groups.
6. Used ls -l and sta to verify permissions.
7. Tested file access using different Linux users.
## Commands Practiced 
- chmod
- chown
- chgrp
- ls -l 
- stat
- sudo -u

## Learning Outcomes 
Learned how Linux manages file ownership and permissions using owners, groups and other users.

Also learned that group memebership alone does not override restrictive file permissions.
