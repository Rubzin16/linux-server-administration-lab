# Linux System Monitoring 

## Objective 
Learn how to monitor Linux system performance, memory, disk space and running processes.

## Tasks Completed

1. Checked system uptime and load average.
2. Inspected RAM and swap usage.
3. Checked available disk space.
4. Monitored live CPU and memory usage.
5. Inspected running processes.

## Commands Practiced

 - uptime
 - free -h
 - df -h 
 - top 
 - ps aux 
 - ps aux | head -10

## Learning Outcomes 

Learned how to monitor Linux system resources and identify potenial performance issues.

Understood the difference between physical memory, swap memory and available memory.

Learned how to inspect running processes, identify process IDs and examine resources usage.
