# Linux Bash Scripting

## Objective 
Learn how to automate Linux administation tasks using Bash scripting.

## Project: System Information Script

Create a Bash script called system-info.sh to automate the collection and display of system information.

## Commands and Concepts Practised

 - Bash scripting 
 - echo 
 - data
 - hostname
 - uptime 
 - free -h 
 - df -h /
 - chmod +x
 - Script execution using ./

## Learning Outcomes

Learned how to create, save and execute Bash scripts.

Understood how to automate multiple Linux administation commands using one script.

Learned how to execute permissions allow scripts to run directly from the terminal.

Successfully created and tested a system information monitoring script.
