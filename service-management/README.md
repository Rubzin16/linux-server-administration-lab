# Linux Service Management 

## Objective 
Learn how to manage Linux services using systemctl on Ubuntu.

## Task Completed
1. Listed currently running services.
2. Checked NetworkManager service status.
3. Restarted the cron service.
4. Stopped the cron service.
5. Started the cron service.
6. Disabled cron automatic startup.
7. Enabled cron automatic startup again.
8. Verified that cron was active and running.

## Commands Practised
 - systemctl list-units
 - systemctl status 
 - systemctl restart
 - systemctl stop
 - systemctl start
 - systemctl enable
 - systemctl disable 
 - systemctl is-enabled

## Learning Outcomes
Learned how to inspect, start, stop and restart Linux service.

Understoop the difference between enabling a service to start automatically at boot and starting a service immediately.

Also learned how to verify service status using systemctl.
