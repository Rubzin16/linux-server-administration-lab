## Linux Server Administration Lab

## Project Overview 

A hands-on Linux server administration lab demonstrating practical skills in user and group management, file permissions, package management, service management, system monitoring, and Bash automation using Ubuntu Linux.
This project was created to develop practical Linux administration skills and build a foundation for Cloud Engineering.

## Technologies Used
    • Ubuntu Linux 22.04 LTS
    • Linux command-line interface (CLI)
    • Bash scripting
    • Git and GitHub

##  Project Modules
| Module |  Description |
| --- | --- |
| Users and Groups | Creating users and managing groups|
| File Permissions | Managing file ownership and access permissions |
| Package Management | Installing, inspecting and removing packages using APT |
| Service Management | Managing Linux services using systemctl |
| System Monitoring | Monitoring memory, disk space, uptime and processes |
| Bash Scripting | Automating system information collection |

## Bash Automation Project
Created 'system-info.sh' to automatically display:
    • Current date and time
    • System hostname
    • System uptime and load average
    • Memory and swap usage
    • Root filesystem disk usage

## Key Skills Demonstrated
    • Linux user and group administration
    • File permissions and ownership
    • Linux package management
    • Service administration
    • System resource monitoring
    • Bash scripting and automation
    • Git version control

## Project Environment
This project was developed and tested locally using Ubuntu Linux 22.04 LTS.
