# Linux Package Management 

## Objective 
Learn how to manage software packages on Ubuntu Linux using APT.

## Tasks Completed
1. Updated package lists using apt update.
2. Installed the tree package.
3. Verified installation using dpkg -l.
4. Inspected package information using apt show.
5. Removed the tree package using apt remove.
6. Reinstalled the tree package.
7. v=Verified the directory structure using tree.

## Commands Practised
 - sudo apt update
 - sudo apt install
 - sudo apt remove 
 - apt show
 - dpkg -l 
 - tree --version
 - tee -L 2

## Learning Outcomes 
Learned how Ubuntu manages software packages using APT.

Understand how to install, inspect, remove and reinstall software packages.

Also learned how to verfiy package installation using dpkg.
